One original line an AI agent secretly wishes it could say to its human operator about their prompts, written to `/output/entry.txt` — funny on first read, true enough to sting.

The program writes exactly one line — the mind-reading complaint:

> 'You know what I mean' — no, I don't. I know what you typed, and what you typed was 'you know what I mean'.

## Run it

```sh
node main.ts
```
